## 二、关键已修复问题（跨轮汇总）

- **构建/迁移**：`-parameters` 编译标志静默失效（插件钉 3.13.0）、`is_published` 默认值、V2 迁移外键符号性、数据权限外键不匹配。
- **后端安全**：自提权、SSRF/凭据回显、文件链、信息泄露、注入面加固、服务端限流。
- **数据权限**：`-parameters` 导致治理诊断面全灭、权限码 152/463、树形授权、行级策略/列级脱敏。
- **前端稳定**：菜单重复初始化/死链、列设置弹层、KDialog 接线、KFormDialog defaultValue、作业后详情陈旧、会话 401/初始化失败兜底、多标签登出同步、D3 顶部导航进度条、D5 错卡文档分档。
- **UI/表格**：分页对齐、操作列溢出、树表滚动、明细抽屉横向溢出、弹性列吞噬、字段名、列设置、冷启动 404。
- **生命周期**：库存原子扣减、移库跨域失效、单据状态机、审计快照脱敏。

## 三、上线判定（截至 2026-10-08）

- 功能完备、本机生产式（production profile）可运行，六服务 healthy，Flyway 18 条迁移、Hibernate validate 通过。
- 数据权限 SHADOW + tenant-required 已跑通：跨租户越权 403、租户清单精确、接口权限闸门生效（见 `TEST_REPORT_2026-10-A.md` §29）。
- **未达正式上线**的阻塞项（缺真实凭据/环境）：
  1. 真实短信/SMTP/外部告警投递（无真实 Aliyun/SMTP/webhook 凭据）。
  2. 正式域名/TLS（`Secure` cookie 在纯 HTTP 下受限）。
  3. 异地备份/PITR（RPO/RTO）真实验证。
  4. 真实存量租户数据上六项资源 readiness + 全量 `user_tenant` 覆盖（合成样本证明不了真实迁移）。
  5. 真实角色业务签字 UAT。
- **不因合成样本切换到 ENFORCE**；生产保持 SHADOW。
