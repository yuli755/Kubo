## 二、换轨模板（从 `wms.input` 提炼，8 步）

1. **Entity**：确认主实体继承 `TenantAwareEntity`（档 B 先改继承链）；关系对象在 resultMap 中只投影 ID。
2. **`XxxMapper.java`**：`@DataResource(key=..., alias=...)` + `implements KuboBaseMapper<XxxEntity>, RowParityCounter`，含 7 个方法：
   `selectPageByPermission` / `selectDetailByPermission` / `countByPermission` / `statByPermission` / `selectForExport` / `countByPermissionFragment` + `parityResourceKey()`。
3. **`XxxMapper.xml`**（`resources/mapper/<模块>/XxxMapper.xml`）：`resultMap`（逐列映射 + 关系 `association` 只投影 id）、`<sql>` 列段 / 业务筛选段 / parity 筛选段（parity 不用别名）、`ORDER BY id DESC`、`LIMIT/OFFSET`。权限条件由 MyBatis-Plus 运行时拦截器按 statement ID 注入，**不在 XML 里手写**。
4. **`XxxReadShadowService.java`**：`submit(filter)` 把业务筛选翻译成 `parameters` + JPA `Specification`（两边口径必须一致，这是影子双跑对账的前提）。
5. **`XxxService.java`**：`isMapperReadEnabled()` + `getMapperPage/getMapperDetail/getMapperCount/getMapperStat`，`mapper-read.enabled=false` 时回退 JPA `getPage/getDetail/...`。
6. **`XxxController.java`**：读出口（page/detail/count/stat/export）改走 Mapper 路径。
7. **测试**：`XxxMapperRuntimeInterceptorTest`（当前租户可见行 + 固定 id 倒序 + 无策略恒假零行 + 导出走同一权限链）；回退测试（`mapper-read.enabled=false` 走 JPA）。
8. **登记**：DevDataInitRunner 补 owner_columns（有归属列的资源）；`八资源读侧导出验收矩阵.md` 补该资源覆盖行。

## 四、每批验收标准（不可放松）

1. 真实 H2 Mapper 链测试通过（statement/策略/fail-closed）；
2. JPA/Mapper parity（影子双跑）测试通过，两遍行数一致；
3. `mapper-read.enabled=false` 时 Service/Controller 回退 JPA 的功能级测试通过；
4. 导出取数走同一权限链（当前租户可见行 + 无策略恒假零行）；
5. `pnpm ddl:check` / `text:check` / `perms:check` 全绿；CI 三 job 全绿。
