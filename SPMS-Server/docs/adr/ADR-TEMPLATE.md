# 附录：常用决策维度清单

技术选型时建议从以下维度评估：

| 维度 | 关键问题 |
|------|----------|
| **功能适配性** | 是否满足核心业务需求？是否支持未来扩展？ |
| **技术成熟度** | 社区活跃度、版本稳定性、已知 Bug 数量 |
| **团队熟悉度** | 团队现有技能覆盖度、学习曲线陡峭程度 |
| **生态系统** | 周边工具、中间件、监控、CI/CD 集成度 |
| **性能表现** | 吞吐量、延迟、资源占用、扩展性 |
| **运维复杂度** | 部署难度、监控告警、故障排查、升级维护 |
| **成本** | 许可证、硬件资源、人力维护、培训 |
| **安全合规** | 数据加密、审计、权限控制、合规认证 |
| **供应商锁定** | 是否强绑定特定云厂商/供应商 |
| **社区支持** | 文档完整度、Issue 响应、商业支持可用性 |
