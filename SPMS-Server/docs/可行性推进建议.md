## 4. 风险与注意事项（诚实）

1. **后端未编译是当前最大风险**：111 文件改动无编译验证，阶段 1 可能暴露问题，属预期、不是意外。
2. **迁移脚本需 MySQL 8 方言**：H2 + `schema-test.sql` 是手抄件，`migrations` CI job（真实 MySQL 8）
   才是方言权威；本机首次跑迁移务必先备份。
3. **docker-compose 凭据**：本地观测栈是弱默认凭据 + 端口未绑 `127.0.0.1`，**严禁**原样部署到可达服务器。
4. **Cookie SameSite/Secure**：认证 Cookie 已改 HttpOnly，但 SameSite/Secure 属性由
   `CookieHelper` 框架默认决定，部署 HTTPS 后需在网关/框架层确认 Secure 置位（随 P1 上线核对）。
5. **采集端协议变更**：设备 API-Key（A1）落地后，采集端需携带 `apiKey` 字段发版，否则设备数据上报断链。
