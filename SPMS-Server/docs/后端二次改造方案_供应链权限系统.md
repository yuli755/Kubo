# Kubo 平台供应链权限治理 后端二次改造方案

**版本**：2.0  
**生成时间**：2026-08-17  
**状态**：🟢 可交付方案  
**目标**：基于现有 Spring Boot + AirPower + JPA/Hibernate 进行最小侵入改造，完成行级 + 列级数据权限治理

---

## 一、改造目标

**核心能力**：
- 行级权限：在 MyBatis 拦截器阶段动态注入 WHERE 条件
- 列级权限：通过 AOP 切面动态脱敏响应字段
- 接入方式：新业务表无需修改业务代码即可接入
- 一致性：权限变更后，Redis + 本地缓存 + 数据库最终一致
- 性能：权限规则缓存命中后，降低 gRPC 调用开销

---

## 二、技术栈调整（最小侵入）

| 维度 | 当前 | **改造后** | 改造方式 |
|------|------|------------|----------|
| ORM | JPA/Hibernate | 保留 JPA + 补充 MyBatis-Plus | 逐步迁移部分模块 |
| SQL 拦截 | 无 | **MyBatis 拦截器** | 新增 DataPermissionInterceptor |
| 列级脱敏 | 无 | **AOP + 自定义注解** | 新增 ColumnMaskingAspect |
| 缓存 | 部分 Redis | **本地缓存 + Redis 版本化缓存** | 新增 PermissionCache |
| 消息一致性 | 无 | **Outbox + RabbitMQ** | 新增 PermissionOutboxService |

```sql

CREATE TABLE data_resource (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  resource_key VARCHAR(100) UNIQUE NOT NULL COMMENT '权限资源标识，如 wms.inventory',
  table_name VARCHAR(100) NOT NULL,

  owner_columns JSON COMMENT '所有者字段数组',

  version BIGINT DEFAULT 1,

  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_by BIGINT,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- data_policy.sql
CREATE TABLE data_policy (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  policy_code VARCHAR(100) UNIQUE NOT NULL,
  resource_key VARCHAR(100) NOT NULL,
  action VARCHAR(20) NOT NULL,
  effect ENUM('ALLOW','DENY') DEFAULT 'ALLOW',
  condition_json JSON NOT NULL COMMENT '结构化条件树',
  priority INT DEFAULT 0,
  version BIGINT DEFAULT 1,
  status TINYINT DEFAULT 1,
  created_by BIGINT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- data_field_policy.sql
CREATE TABLE data_field_policy (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  resource_key VARCHAR(100) NOT NULL,
  field_path VARCHAR(200) NOT NULL COMMENT 'DTO字段路径，如 purchasePrice',
  sensitive_type VARCHAR(50) COMMENT '敏感类型',
  mask_strategy VARCHAR(50) DEFAULT 'PARTIAL',
  allow_export_plain TINYINT DEFAULT 0,
  version BIGINT DEFAULT 1,
  status TINYINT DEFAULT 1
);

-- permission_change_outbox.sql
CREATE TABLE permission_change_outbox (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  event_id VARCHAR(50) UNIQUE NOT NULL,
  aggregate_type VARCHAR(50) NOT NULL,
  aggregate_id VARCHAR(100) NOT NULL,
  before_version BIGINT,
  after_version BIGINT,
  event_payload JSON,
  status TINYINT DEFAULT 0,
  retry_count INT DEFAULT 0,
  next_retry_time TIMESTAMP,
  last_error TEXT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_status (status)
);
```

### 3.2 核心组件实现

**1. PermissionContextResolver**（接口）

```java
public interface PermissionContextResolver {
    PermissionContext resolve(HttpServletRequest request);
}
```

**2. PermissionRuleProvider**（核心接口）

```java
public interface PermissionRuleProvider {
    List<PermissionRule> getRules(String resourceKey, String action, PermissionContext context);
}
```

**3. DataPermissionInterceptor**（MyBatis 拦截器）

```java
@Intercepts({
    @Signature(type = Executor.class, method = "query", args = {Statement.class, ResultHandler.class}),
    @Signature(type = Executor.class, method = "update", args = {MappedStatement.class, Object.class})
})
public class DataPermissionInterceptor implements Interceptor {
    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        // 动态注入 WHERE 条件
        return invocation.proceed();
    }
}
```

**4. ColumnMaskingAspect**（AOP 切面）

```java
@Aspect
@Component
public class ColumnMaskingAspect {
    @Around("@annotation(SensitiveField)")
    public Object around(ProceedingJoinPoint joinPoint, SensitiveField annotation) throws Throwable {
        // 动态脱敏逻辑
        return joinPoint.proceed();
    }
}
```
