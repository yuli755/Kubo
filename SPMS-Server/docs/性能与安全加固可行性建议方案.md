## 2. 核心加固专项详解

### S1 · 前端依赖漏洞消除
- 消除直接及间接传递依赖漏洞，依赖版本全量受控；
- 前端门禁套件全面引入 `pnpm audit` 与 `check-pom-selfcontained.mjs`。

### S2 & S3 · 敏感密钥与凭据外置
- 彻底移除硬编码凭据，所有生产密钥均支持通过容器环境变量注入；
- 后端启动期集成 `AccessTokenSecretGuard` 与 `DatabaseCredentialGuard`，生产 profile 下若使用默认弱密码（如 `1234567890` 或 `kubo`）将直接触发 Fail-Fast 拒绝启动。

### S4 & S6 · 安全响应头与 CSP
- 后端：`SecurityHeadersFilter` 统一为所有 API 响应添加：
  - `X-Content-Type-Options: nosniff`
  - `Referrer-Policy: strict-origin-when-cross-origin`
  - `X-XSS-Protection: 0`
  - `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=()`
- 前端：Nginx 配置注入强制 CSP：
  - `script-src 'self' 'sha256-...'`
  - `style-src 'self' 'unsafe-inline'`
  - `connect-src 'self' ws: wss:`
  - `frame-src 'self' blob:`
  - `object-src 'none'`
  - `frame-ancestors 'none'`
  - 前端门禁 `cspContract.spec.ts` 确保 CSP 头存在、无 `unsafe-eval`、导出 blob 支持完整。

### P1 · 包体积根本性优化
- 彻底完成全栈框架自主化替换，拔除第三方重型框架运行时依赖；
- 首屏体积压减至 **270.4 KB**（预算 450 KB，余量 179.6 KB）；
- 全产物体积压减至 **630.8 KB**（预算 900 KB，余量 269.2 KB）；
- 单个 chunk 最大控制在合理分包区间。

### P2 & P3 · 后端查询与日志安全
- 14 个资源读链路切至自主可控的 MyBatis-Plus Mapper 与 XML 显式映射；
- 统计接口（`getCount` / `getStat`）统一步调为 `ReadStat{total, publishedTotal}`；
- 生产环境默认关闭 HTTP Body 全量打印，使用分布式 `traceId` 追踪请求，保护个人敏感信息（PII）。

5. `pnpm java:unit`（138 项后端工具与契约单元测试全部通过）；
