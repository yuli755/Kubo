## P2 · 前端交互与人体工学深化演进（本轮已全量落地 1~9 ✅）

1. **全局命令调色板（Command Palette `Ctrl + K` / `Cmd + K`）—— 已落地 ✅**：
   - 现已提供 `KCommandPalette.vue` 并集成于 `KAppShell.vue` 顶栏与全局快捷键（`Ctrl+K` / `Cmd+K`）；
   - 支持跨模块平发展平模糊检索菜单、一键直达控制台各业务路由、快速执行切换主题（明亮/暗黑）与展开/折叠侧边栏；
   - 键盘 `↑` / `↓` 上下穿梭、`Enter` 即刻触发、`Esc` 敏捷退回，60ms 极速响应。
2. **大表单本地草稿自动暂存（Draft Autosave）—— 已落地 ✅**：
   - 现已在自研框架表单弹窗 `KFormDialog.vue` 中内置自动暂存机制；
   - 新增实体场景下对用户输入自动进行 600ms 防抖暂存（Scoped Key `kubo:draft:<ServiceName>`）；
   - 再次打开时智能识别未保存历史草稿，醒目弹窗提供「恢复草稿」与「放弃草稿」操作，提交成功后自动清理垃圾草稿，彻底杜绝误触或断网造成的长单据重填痛苦。
3. **表格多列自定义与视图偏好持久化（Column Customization）—— 已落地 ✅**：
   - 现已在通用表格组件 `KTable.vue` 工具栏右侧集成「列显隐设置」Popover；
   - 动态解析当前表头字段，支持自由勾选隐藏非关注字段、实时更新表格渲染宽度并自动收敛；
   - 用户偏好自动持久化至 `localStorage`（Key `kubo:table:columns:<queryKey>`），支持一键还原默认列布局。
4. **离线感知与断网温和降级提示横幅（Offline Banner）—— 已落地 ✅**：
   - 在 `KAppShell.vue` 顶层接入 `online` / `offline` 真实网络事件监听；
   - 断网时在控制台主工作区置顶渲染非阻塞警告横幅，并在顶栏操作区呈现「离线模式」状态徽标，提示用户进入只读保护；
   - 重新联网时自动触发温和 Toast 通知（「网络连接已恢复」），与已有的 PWA Service Worker 离线缓存策略无缝衔接。
5. **列表表格全局快捷键增强（`/` 键快速聚焦搜索）—— 已落地 ✅**：
   - 在通用表格 `KTable.vue` 中实现全局快捷键监听，在非输入焦点状态下按下 `/` 键即可秒级聚焦至搜索框首个输入项；
   - 首个输入框 placeholder 智能增设 `(按 / 聚焦)` 操作指引，按下 `Enter` 触发查询、支持纯键盘盲操。
6. **WMS 入库单条码枪连续扫码录入模式（Continuous Barcode Scanning）—— 已落地 ✅**：
   - 在入库单编辑器 `editor.vue` 明细头部集成物理扫码枪专用连续录入输入框；
   - 扫码枪扫入物料条码并自动触发 `Enter` 时：若明细列表已存在该物料，自动累加数量（`quantity + 1`）；若不存在则自动新增该物料行并继承仓库配置，实现仓储作业流水线的高速录入。
7. **WMS 出库单与移库单扫码录入模式横向覆盖 —— 已落地 ✅**：
   - 将扫码累加能力延伸覆盖至出库单编辑器（`output/.../editor.vue`）与移库单编辑器（`move/.../editor.vue`）；
   - 扫入物料条码自动匹配或建行，出库作业与移库换仓支持纯条码连续扫录，大幅提升仓储拣货与复核效率。
8. **实时库存全景指标汇总卡（Inventory Metric Summary Bar）—— 已落地 ✅**：
   - 在「实时库存」页面（`wms/inventory/list.vue`）顶部新增全景指标卡；
   - 实时聚合当前维度下的总在库物料 SKU 种数、总库存件数，以及库存不足 10 件的低库存预警统计，高亮警示库存缺口。
9. **通用单据详情打印与电子凭证（Print Voucher View）—— 已落地 ✅**：
   - 在自研通用详情组件 `KDetail.vue` 标题栏右侧集成「打印单据」快捷功能；
   - 调取系统原生打印驱动（`window.print()`），内嵌专用 `@media print` 样式隔离无关按钮，满足仓储出入库交接、采购验收的纸质小票与凭单归档需求。

## P3 · 业务功能深化与企业级扩展建议

1. **WMS 智能仓储深化与库位热力图**：
   - **库位可视化（Warehouse 2D/3D Map）**：结合 ECharts 渲染库区平面图谱，直观显示各货架/库位占用率与堆放热力，支持图形化点击库位反查库存批次。
   - **手持机盘点作业全闭环**：出库单与移库单进一步铺开批次条码校验逻辑，扫码时比对批次号与保质期，杜绝错发漏发。
   - **库存呆滞与临期预警**：根据入库批次时间戳计算库龄，在工作台「业务态势」提供呆滞料与临期批次预警面板。
2. **企业级协同与通知通道集成**：
   - 完善基于飞书（Feishu）、企业微信（WeCom）、钉钉（DingTalk）机器人的审批流与死信告警 Webhook 推送。
   - 实现单据审核驳回时的即时通讯通知与邮件提醒。
3. **CI/CD 构建流水线成本与镜像瘦身**：
   - 在 GitHub Actions 账单限额解除后，启用 `dependency:analyze` 报告自动化核验，移除未用依赖。
   - 优化 Docker 多阶段构建镜像，前端采用 nginx alpine 最小化镜像（目标 < 30 MB），后端采用 Eclipse Temurin 17 JRE Alpine 镜像（目标 < 180 MB）。
