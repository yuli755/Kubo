## 三、后端架构（全量自持现代 Spring Boot 体系）

| 能力 | 实现 | 备注 |
| --- | --- | --- |
| 分层体系 | Controller → Service → Repository | `base/` 提供全自持 `BaseController`、`BaseService`、`BaseEntity`、`BaseRepository`，零继承外部私有框架 |
| CRUD 引擎 | 全自持基类驱动 | 通过自持泛型反射与 Spring Data JPA 实现新增、更新、根据 ID 查询详情与分页查询 |
| 权限体系 | `@Permission` 注解 + `RequestInterceptor` + `PermissionScanner` | 35 控制器 134 端点显式鉴权；`pnpm auth:check` 与 `perms:check` 硬门禁 100% 通过 |
| 多租户隔离 | `TenantContextResolver` + `TenantAwareEntity` + `DataPermissionInnerInterceptor` | 拒绝伪造 `X-Tenant-Id`，请求结束生命周期严格强制清理上下文 |
| 认证安全 | 自包含 JWT 签名 + `AccessTokenSecretGuard` + Redis 吊销名单 | 弱密钥启动直接 fail-fast；登出黑名单带 TTL 自动过期 |
| 审计追踪 | `operation_log` + `permission_change_outbox` | Flyway V1~V10 增量版本化迁移，支持死信处置与审计回溯 |
| 导出安全 | `EntityCsvExport` + `ExportColumnMasker` + `CsvText.protectFormula` | 实体深拷贝列遮蔽避免脏写回库，公式注入防护强制转义危险前缀 |
| 上传存储 | 本地/对象存储（`spms.upload`） | 强制白名单校验、路径穿越防护与安全隔离 |

**数据面**：MySQL 8（业务持久化）+ Redis 7（缓存/会话/防爆破）+ Flyway（结构版本化管控）；MyBatis-Plus 3.5.9 驱动读加速与行级数据权限拦截，Spring Data JPA 自持负责标准 CRUD 持久化写链路。
