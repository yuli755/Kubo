## 2. 数据权限五大出口全链路点验

### 2.1 租户隔离屏障（Tenant Isolation）
- **请求头探针防御**：`TenantContextResolver` 严格拒绝前端伪造的 `X-Tenant-Id`。必须通过当前认证用户绑定且启用的租户关系解析，非 root 用户越权访问直接阻断；
- **多租户上下文生命周期**：`RequestInterceptor.preHandle` 绑定上下文，`afterCompletion` 强制调用 `PermissionContextHolder.clear()` 与 `Tracer.clear()`，彻底杜绝线程池复用污染。

### 2.2 行级策略过滤（Row-Level Security）
- **MyBatis-Plus Mapper 读加速与拦截**：`DataPermissionInnerInterceptor` 对 14 个核心资源自动拼装所属部门、工厂、仓库维度过滤条件；
- **回滚与降级保障**：`kubo.data-permission.mapper-read.enabled` 开关可无缝回退至 JPA 读路径，`MapperReadFallbackTest` 持续保证并存安全。

### 2.3 写路径归属防篡改（Write Path Tampering Prevention）
- **实体只读字段保护**：`BaseEntity.excludeReadOnly()` 与 `BaseController` 在 `add` / `update` 入口强制过滤只读字段；
- **单据状态机控制**：`BaseBillController` 严格限制只允许由内部单据流推进状态，禁止直接通过通配 update 接口篡改账实状态。

### 2.4 列级字段脱敏（Column-Level Desensitization）
- **自持脱敏引擎**：`@Desensitize` 注解与自持 `DesensitizeType`（手机号、身份证、邮箱、中文名）独立生效；
- **导出列级遮蔽**：`ExportColumnMasker` 在执行异步导出前深拷贝实体副本，在请求线程上下文完成列遮蔽，杜绝持久化上下文脏写回库。

### 2.5 导出防旁路与 CSV 注入防护（Export Safety）
- **防旁路守卫**：`ExportBypassGuard` 在请求线程对未取得 EXPORT 权限的字段进行严格校验拦截；
- **CSV 公式注入防护**：自持 `CsvText.protectFormula` 强制对 `=`, `+`, `-`, `@`, `\t`, `\r`, `\n` 等危险公式前缀进行转义，彻底阻断利用 Excel/WPS 执行远程命令的攻击向量。

## 3. 容器化部署与监控灾备体系就绪

### 3.1 Docker 多阶段构建与生产加固
- **前端 Dockerfile**：Node 20 Alpine 构建，强制使用 `corepack pnpm install --frozen-lockfile`，Nginx Alpine 生产底座；
- **后端 Dockerfile**：JDK 17 Amazon Corretto 构建镜像，生产镜像使用 `amazoncorretto:17-alpine`，已剥离所有多余编译器与调试工具；
- **启动安全守卫**：`AccessTokenSecretGuard` 在未注入随机 JWT 密钥时拒绝启动，防止弱口令上线；
- **Nginx 反向代理与安全头**：
  - `upstream backend { server kubo-server:8080; }`
