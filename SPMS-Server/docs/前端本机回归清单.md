## 一、启动

```bash
pnpm install
pnpm dev        # 前端 http://localhost:3000（demo 预览：pnpm dev:demo）
# 后端按 SPMS-Server 的本地启动方式拉起（数据库 + 服务）
```

## 三、登录 / 鉴权链路

- [ ] 登录：账号密码 → 跳转控制台
- [ ] 刷新后 token 不丢（token 存 localStorage `Authorization`，见 `src/utils/authStorage.ts`）
- [ ] 退出登录：吊销服务端会话 → 清本地状态 → 清权限缓存 → 整页跳登录
- [ ] token 过期 → 自动 refreshToken 或跳回登录
- [ ] 顶栏头像菜单：账号安全中心（改密码 / 私人令牌）、头像上传、实名/邮箱/手机绑定入口

## 四、菜单 / 权限

- [ ] 不同角色登录，左侧菜单按权限正确渲染
- [ ] 无权限页面跳 `/403`；手动输入不存在的路径显示 `/404`（错误页不再有"停留 5 秒"的兜底）
- [ ] 按钮级 `v-permission`：无权限的增删改按钮隐藏

## 五、一处需你确认的语义变化（历史遗留，仍未确认）

`@/utils/validators.ts` 复刻 airpower `ValidateUtil.isNaturalNumber` 时，把原正则
`^\d+((.)\d+)?$` 的**未转义点号 `(.)`** 修正为小数点 `\.`。原实现疑似上游笔误（`(.)`
匹配任意字符）。请确认登录页**小数输入**场景行为符合预期。

## 六、体积门禁参考

```bash
pnpm build && pnpm size
# 应输出：首屏 270.4/450 KB · 总体 630.4/900 KB ✅ 达标
```

若你本机数字与上述有差异，通常是依赖版本 / lockfile 差异，重点看是否「达标」而非绝对数字。
