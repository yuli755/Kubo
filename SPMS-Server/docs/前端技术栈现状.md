## 六、守护这些结论的门禁

| 门禁 | 命令 | 拦什么 |
| --- | --- | --- |
| 死代码 | `pnpm deadcode:check` | **没有任何 import 或路径字符串引用**的文件（`scripts/find-unused-frontend.mjs`；相对路径/别名/动态 import/路由字符串都算引用，视图页由菜单契约测试单独守） |
| 类型 | `pnpm typecheck` | `vue-tsc` 全量 |
| 规范 | `pnpm lint:ci` | ESLint（含 `no-restricted-imports`：视图层不得直接 import `@/model` 的 Service） |
| 单元测试 | `pnpm test` | 44 文件 / 375 用例（含逐页冒烟探针） |
| 体积 | `pnpm size` | 首屏 ≤450 KB、总体 ≤900 KB —— 当前 **343 / 715 KB** |
| 演示产物 | `pnpm demo:check` | 生产产物里不得残留演示开关/mock 标记 |
| 菜单契约 | `src/config/__tests__/menuContract.spec.ts` | 菜单 ↔ 视图 ↔ 后端种子三方一致，且**没有"做了页面却点不到"的孤儿页** |

## 七、目录职责（前端）

```
src/
├── framework/   换底座后的地基（原 @airpower/web 的契约替代）：元数据/实体/HTTP/查询/校验/反馈/枚举/格式化/单元格
├── base/        KEntity（新底座实体基类，F4 逐域启用）；BaseEntity/AbstractBaseService（存量，待删）
├── component/   框架组件（component/framework/*：KTable/KFormDialog/KPanel/KSelector/KDetail）+ 业务公共件
├── hook/        数据层：kubo/（新底座 useTable/useDetail）、<域>/（既有域 hook，逐域迁移）
├── model/       实体与服务（过渡期实体同时挂 airpower + framework 两套装饰器）
├── view/        页面（路由路径 == 视图路径，菜单由后端下发 / 演示模式用 fixtures）
├── api/         axios 实例 + 按域 typed client（openapi 生成）
├── demo/        演示模式（mock 适配器 + fixtures），真实后端接入后可整体拆除
├── config/      路由/权限码/构建开关 + 契约测试（门禁都在这）
└── stores/ directives/ guard/ router/ utils/ styles/ pwa/
```
